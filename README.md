# POLFORGE

A hash floor that pays play-credit POL. Pulse spikes the rate for six seconds. Cards, cooling, and breakers change how hard the floor runs.

This is not on-chain mining, and the balance is not cash. Polygon uses proof-of-stake, so a browser cannot mine it. The price on the floor is Coinbase's public POL-USD ticker.

## Run

```bash
npm install
npm run dev
```
